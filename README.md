# Transparent-Hud
Control the transparency of inventory and container UI backgrounds using the slider! 

This mod lets you make every inventory & container interface see-through. While you're in a GUI, a small draggable panel shows two sliders:

- **UI Alpha** — the opacity of the interface itself (0 = invisible, 1 = default)
- **Background Alpha** — how dark the dim layer behind the screen is

Works with chests, furnaces, crafting tables and basically every inventory-style screen, including your survival/creative inventory and the hotbar.

It's **client-side only** — it changes nothing for other players and is safe to use on any server.

**More:**
- Settings screen (press **`J`** in-game) with extra options like **intelligent transparency**, which automatically adjusts the UI opacity to the brightness of your surroundings.
- Optional HUD info text showing your coordinates, current transparency and ping / local latency (color-coded).
- All settings are saved to a config file and restored on next launch.
- Client commands: `/cabbagemod help`, `/cabbagemod inventoryalpha <0~1>`, `/cabbagemod graybgalpha <0~1>`.

## 中文版

这个模组能让你打开的任何物品栏与容器界面变得透明。进入界面后，会出现一个可拖动的小控制条，上面有两个滑条：

- **UI 透明度** —— 控制界面本身的不透明度（0 = 完全透明，1 = 原版外观）
- **背景透明度** —— 控制界面后方压暗层的浓度

箱子、熔炉、工作台以及几乎所有物品栏类界面都支持，也包括你的生存/创造物品栏和快捷栏。

本模组**仅客户端生效**，不会影响其他玩家，任何服务器均可放心使用。

**更多功能：**
- 游戏内按 **`J`** 打开设置界面，可选**智能透明度**：让界面透明度随周围环境亮度自动变化。
- 可选 HUD 信息文本：显示坐标、当前透明度，以及联机 Ping / 单机延迟（按质量着色）。
- 所有设置自动保存到配置文件，下次启动自动恢复。
- 客户端指令：`/cabbagemod help`、`/cabbagemod inventoryalpha <0~1>`、`/cabbagemod graybgalpha <0~1>`。
